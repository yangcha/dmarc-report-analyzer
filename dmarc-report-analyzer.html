How to read the results

This tool reads DMARC aggregate (RUA) reports. Each table row is a record from the report; an IP may appear more than once when its authentication results differ. When several files or a folder are loaded, all reports are combined into one view: records with the same IP and results are merged and their message counts summed.

  • Messages: the number of messages represented by each record.
  • DKIM and SPF: the receiver’s aligned results from policy_evaluated, not the raw authentication results.
  • DMARC: passes when either aligned DKIM or aligned SPF passes. If both fail, DMARC fails.
  • Disposition: the receiver’s reported action: none, quarantine or reject. A DMARC failure does not always cause rejection.

A ZIP may contain several XML reports; all of them are read and combined. Encrypted and ZIP64 archives are not supported. Compressed uploads require a recent browser with native decompression support.
